# ShadowFox Python Development Internship

## Beginner Level Tasks

This repository contains my solutions for the Beginner Level tasks of the ShadowFox Python Development Internship.

According to the internship task list, the Beginner Level requires completion of 5 out of 9 tasks.

## Completed Tasks

### Task 1 — Variables

Topics covered:

* Variables
* Data types
* Python reserved keywords
* Simple Interest calculation

### Task 2 — Numbers

Topics covered:

* `format()` function
* Arithmetic calculations
* Circle area
* Water volume calculation
* Speed calculation

### Task 3 — List

Topics covered:

* Creating lists
* Adding elements
* Removing elements
* Inserting elements
* Finding indexes
* Sorting lists

### Task 4 — If Condition

Topics covered:

* User input
* BMI calculation
* `if`, `elif`, and `else`
* Lists
* Functions
* Comparing values

### Task 5 — For Loop

Topics covered:

* `for` loops
* Random numbers
* Counters
* Conditional statements
* Loop control using `break`
* User interaction

## How to Run

Make sure Python is installed on your computer.

Open the project folder in VS Code or a terminal.

Run an individual task using:

```bash
python beginner_tasks/task1_variables.py
```

Replace the filename with the task you want to execute.
