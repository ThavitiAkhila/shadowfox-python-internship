# Hangman Game

## ShadowFox Python Development Internship

This project implements a command-line Hangman word-guessing game using Python.

## Features

- Random word selection
- Categories
- Hints
- Letter guessing
- Wrong guess tracking
- Visual Hangman progress
- Win detection
- Lose detection
- Repeated-letter validation
- Play again option

## Technologies Used

- Python
- Random module

## How to Run

```bash
python hangman.py
